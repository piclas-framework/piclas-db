# Tutorials

| # | Tutorial | For |
|---|---|---|
| [T1](T1-getting-started.md) | Getting started: install, set up, check a database, build the GEC argon database, use it in PICLas | everyone |
| [T2](T2-checking-and-comparing.md) | Checking and comparing existing databases: check, repair, diff, plot, export, sources | everyone with database files |
| [T3](T3-adding-data.md) | Adding data: identity, download guide, import, store | everyone who adds data |
| [T4](T4-private-repository.md) | The private source repository: set up, team workflow, backup | data maintainers, groups |

The tutorials use PICLas files (GPL) and data you download yourself: LXCat, NIST and papers must not be redistributed, so no
tutorial ships such data. Commands are written for bash on Linux.
